# 実装計画：Hand Game のデバッグと最適化

## 概要
`test.py` が即座に終了してしまう問題に対処するため、カメラの初期化プロセスの堅牢性を高め、MediaPipe の動作モードを動画ストリーム向けに最適化します。

## 変更内容
1. **カメラ初期化の強化**:
   - `cap.isOpened()` チェックをループ前に行い、失敗時に明確なエラーメッセージを表示。
2. **MediaPipe VIDEO モードへの変更**:
   - `HandLandmarkerOptions` で `running_mode=vision.RunningMode.VIDEO` を設定。
   - `detector.detect_for_video` を使用し、フレームごとのタイムスタンプ（ミリ秒）を渡す。
3. **推論ループの改善**:
   - `cap.read()` の戻り値を厳密にチェック。
   - 残り時間の計算と表示を安定させる。

## 検証計画
- `python test.py` を実行し、カメラ映像のプレビューが正常に表示されることを確認。
- ランドマークが正しく描画され、ゲームロジックが機能することを確認。
- 30秒後に正常に終了し、スコアが表示されることを確認。
