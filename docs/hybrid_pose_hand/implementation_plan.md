# 実装計画：ハイブリッド姿勢・手推定

## 概要
全身の動きを捉える `PoseLandmarker` と、指先の詳細な動きを捉える `HandLandmarker` を並列で動作させ、1つの映像内に統合して描画します。これにより、姿勢推定を行いながら高いハンドレスポンスを実現します。

## 変更内容
1. **新規ファイル `hybrid_test.py`**:
   - 2つの検出器（Pose & Hand）を初期化。
   - 同一フレームに対して両方の推論を実行。
   - 青色の骨格（Pose）と緑色の指先（Hand）を重ねて描画。
2. **モデルファイル**:
   - `pose_landmarker.task` と `hand_landmarker.task` を使用。

## 検証計画
- `hybrid_test.py` を実行。
- 身体を動かした際の骨格表示と、手を動かした際の指先表示が同時に行われることを確認。
- 推論負荷による極端なカクツキがないか確認。
