# ウォークスルー：Hand Game のデバッグと最適化

## 修正の概要
- Webカメラの起動チェックを追加
- MediaPipe HandLandmarker を VIDEO モードに変更し、パフォーマンスと安定性を向上
- デバッグ用のログ出力を追加

## 主な変更点
- `test.py`:
  - `vision.RunningMode.VIDEO` の導入
  - `detect_for_video` への切り替え
  - カメラ接続失敗時のガード条件を追加
  - **カメラの初期化にリトライ処理を追加（インデックス 0, 1 を試行）**

## 検証結果
- [x] カメラが起動し、ゲームが開始される
- [x] スコア加算が正常に行われる
- [x] 制限時間終了時にスコアが表示される

## 追記
調査により、カメラのインデックスが環境によって 0 または 1 になることが判明しました。修正後のコードでは両方のインデックスを自動で試行し、正常に動作する方を採用するようになっています。また、MediaPipe の推論モードを動画ストリーム（VIDEOモード）に最適化したことで、より安定した動作が確認できました。
