# 実装計画書 - ピースサイン・フォトキャプチャ

## 目的
MediaPipeを使用したポーズ・手検出スクリプト `hybrid_test.py` を拡張し、特定のジェスチャー（ピースサイン）をトリガーとした自動撮影アプリを実現する。

## 実装内容

### 1. 状態マシンの導入
アプリケーションに以下の3つの状態を持たせる：
- `STATE_WAITING`: ピースサインを待機している状態。
- `STATE_COUNTDOWN`: ピースサイン検出後、3秒間のカウントダウンを行っている状態。
- `STATE_PHOTO_TAKEN`: 写真を保存し、完了メッセージを表示している状態。

### 2. 撮影ロジック
- **トリガー**: `check_gestures` 関数が "Peace!" を返した場合にカウントダウンを開始。
- **保存画像**: アノテーション（骨格やテキスト）が描画される前の「クリーンなフレーム」を保存用にコピーして保持する。
- **ファイル名**: `group_photo_YYYYMMDD_HHMMSS.png` の形式で実行ディレクトリに保存。

### 3. UI/UXの改善
- カウントダウン中は画面中央に大きな数字を表示。
- 撮影完了後は「Photo Saved!」と表示し、数秒後に自動で待機状態に戻る。
- 待機中は「Peace to Take Photo」というガイドを画面下部に表示。
