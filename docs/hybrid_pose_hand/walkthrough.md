# ウォークスルー：ハイブリッド姿勢・手推定

## 実装のポイント
- 複数の `VisionTask` クラスの同時運用。
- フレームごとの同期推論処理。
- 重層的な描画（Pose接続線 + Hand接続線）。

## 検証結果
- [x] 全身骨格の表示
- [x] 指先21箇所の詳細表示
- [x] リアルタイム性の維持

## 負荷検証について
画面左上に現在のFPS、CPU使用率、および検知設定（最大人数/手）を表示する機能を実装しました。これにより、ハードウェアの性能に応じた最適なパラメータを特定することが可能です。

## ポータビリティ
`requirements.txt` を生成し、Windows などの他環境でも同様の動作を再現できるようにしました。
